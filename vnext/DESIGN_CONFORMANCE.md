# DADS準拠メモ

現行Noemaはデジタル庁デザインシステム（DADS）の公式HTML実装とデザイントークンを基準にしています。デジタル庁サイトそのものの複製ではなく、Noema固有の情報設計にDADSの規則とコンポーネントを適用します。

## 参照元

- 公式リポジトリ: `digital-go-jp/design-system-example-components-html`
- 固定コミット: `3b34f4c3553fa3bee90bfd8b6fe962ac3055107d`
- 取得日: 2026-07-10
- ライセンス: MIT
- 公式CSSの配置: `packages/ui/src/styles/official`

出典の詳細は `packages/ui/SOURCE.md` に記録しています。公式CSSは機械的にコピーし、Noema固有の調整は `packages/ui/src/styles/noema.css` と各アプリのCSSへ分離しています。

| 画面要素 | DADS基準 | Noemaでの使用 |
| --- | --- | --- |
| ボタン | `button.css` | 記事検索、質問送信、CMS保存、Markdown書き出し、レビュー・公開操作 |
| リンク | `link.css` | ナビゲーション、パンくず、記事内リンク |
| パンくず | `breadcrumb.css` | 記事の現在位置 |

## Noema固有の判断

- DADSのカラーロールを維持しながら、キーカラーをNoema固有の深い青緑、背景を温かいオフホワイトへ置き換える。
- 公開ブログは記事一覧と注目記事に限って外周付きの角丸カードを使用する。
- 記事タイプは公開せず、体験・活用記事を大きく、開発・理論記事を小さく配置する。
- 記事カードは記事タイプ色1pxの四辺外周と24px角丸を持ち、左辺だけの線や分類色の面塗りを使わない。
- カード全体を単一リンクにし、タイトルを常時下線付きにする。hoverは各記事の分類色による4pxの内側アウトライン、同色のタイトルと矢印で示し、focusは黒4pxと黄のリングで示す。
- カードのテーマ、タイトル、要約と大小を併用して位置付けを伝える。
- ヘッダーはブランドと検索だけで構成し、用途のないグローバルメニューやモバイルメニューを置かない。
- トップのヒーローはDADSの`Dsp-48B-140`、`Std-17N-170`、1カラムのリキッドレイアウトと既存余白スケールだけを使う。特定記事への導線、独自画像、独自コンポーネントは置かない。
- OIFへの外部リンクはAboutページの運営情報だけに置き、主要ナビゲーションや記事導線へ置かない。
- 本文は読みやすさを優先し、行長と段落間隔を制限する。
- 記事AIはデスクトップでは補助カラム、モバイルでは明示的な固定ボタンから開くモーダルにする。
- Studioは公開サイトと分離し、画面幅にかかわらず本文・プレビュー・設定を明示的なタブで1ペインずつ表示する。本文を最初に置き、プレビューと設定は必要な時だけ開いて作業対象を1つに絞る。
- StudioはCMS保存、レビュー依頼、承認、修正依頼、公開、保管を別の操作として表現し、roleに応じて実行可能な操作だけを提示する。レビュー状態と公開状態、current revisionとpublished revisionを混同しない。
- Noema固有のコンポーネント構造は記事アシスタントの質問カードだけに限定する。文字、見出し、フォーム、ナビゲーション、カードの構造と操作はDADSの定義またはデジタル庁ホームページの適用例に従い、色だけをNoemaのブランド体系へ置き換える。

## タイポグラフィ対応

| 用途 | モバイル | デスクトップ | DADSテキストスタイル |
| --- | --- | --- | --- |
| ページ・記事タイトル | 28px / 150% | 45px / 140% | `Std-28B-150`, `Std-45B-140` |
| 記事本文H2 | 24px / 150% | 32px / 150% | `Std-24B-150`, `Std-32B-150` |
| 記事本文H3 | 22px / 150% | 28px / 150% | `Std-22B-150`, `Std-28B-150` |
| 本文・リード | 17px / 170% | 17px / 170% | `Std-17N-170` |
| 通常UI | 16px以上 | 16px以上 | Standard / Oneline |
| 日付・補助表示 | 14px / 130% | 14px / 130% | Dense |

記事本文の見出しは無装飾とする。DADSではチップや飾り罫も選択可能だが、デジタル庁ホームページの記事適用例に合わせ、Noemaでは左線、チップ、飾り罫、下罫線を使用しない。

## 実装確認

- 1280×720: トップ、記事、Studioで横スクロールなし。Studioは選択中の1ペインだけを表示。
- 320×700、390×844、768×900、901×768、1024×768: Studioで横スクロールなし。Studioは1ペインとタブ表示。
- モバイル目次はキーボードとタッチで開けるネイティブ `details` を使用。
- 記事AIモーダルは開閉時にフォーカスを移動し、Escで閉じられる。
- Studioの全入力に明示的なラベル、サポートテキスト、入力エラーを関連付け、プレビュー内のHTMLをサニタイズ。blocking errorは操作可能な要約から該当frontmatterまたはMarkdown本文行へ移動できる。
- Studioのタブは左右矢印、Home、Endで切り替えられ、主要な入力・ボタン・タブ・Disclosureは44px以上の操作領域を持つ。
- Studioの下書きは必須項目が欠けた状態でもD1へrevisionとして保存でき、ブラウザの復旧コピーからもreload後に復元できる。CMS保存不能時は色とテキストで通知する。
- Studioのreview状態とpublication状態を色だけでなく文言で示し、公開中の記事を編集しても再承認・再公開までpublished revisionが変わらないことを説明する。
- Studioの保存競合は入力内容を保持したまま通知し、Markdown書き出しまたはCMS最新版の読込をキーボードだけでも選択できる。
- 一般公開、限定URL、指定メンバー、運営メンバーのみの違いを文章で示し、限定URLが認証ではないことと指定メンバー公開が未接続であることを伝える。
- 記事Markdownのraw HTMLと危険なURL schemeはStudioとbuildの共通validatorで拒否し、公開rendererでもescapeまたは無効化する。HTMLのコード例はインラインコードまたはコードフェンス内に限って保持する。
- UI確認用fixtureとプレビューURLは公開コンテンツから分離し、検索対象外に設定。
- 1440×1000と390×844で、注目記事の大小、カード外周、テーマ導線を確認。
- 記事本文のH1/H2/H3について、デジタル庁ホームページと同じ28/45px、24/32px、22/28pxの対応と、装飾線がないことを確認。
- 320、390、768、901、1024、1280、1440 CSS pxでStudioの`scrollWidth`がviewport幅と一致し、横スクロールがないことを確認。
- axe-core 4.11.1でトップ、記事一覧、AboutをWCAG 2 A/AA、2.1 AA、2.2 AA対象に検査し、違反0件を確認。
- Noemaのキーカラーと4分類色は、白および背景色`#FAF9F5`に対して5.9:1以上のコントラスト比を持つことを確認。
- 1440×1000と390×844でブログとStudioにNoemaのキーカラー、背景色、4分類色が適用されることを確認。
- トップのヒーローがデスクトップで`Dsp-48B-140`、モバイルで`Std-28B-150`となり、リンクを含まないことを確認。
- 体験・活用・開発・理論カードのhover時に、外周、タイトル、矢印がそれぞれ同じ分類色になることを確認。
- OIFへの外部リンクがAboutページの運営情報だけに存在することを確認。
