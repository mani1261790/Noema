## 利用上の注意

このコピーは実装時の参照と変更差分の追跡を目的とする。Noemaはデジタル庁またはデジタル庁の公式サービスではない。

ガイドラインの内容を利用・加工して公開する場合は、公式の[利用上の注意事項](https://design.digital.go.jp/dads/introduction/notices/)に従って出典を記載する。コード実装には、別途公開されているMIT LicenseのHTML版またはReact版コードスニペットを使用できる。

## 更新方法

新しい公式版へ更新するときは、既存版を上書きせず新しいバージョンディレクトリへ展開し、取得元、取得日、ハッシュを更新する。NoemaのUIへ反映する変更は、[`../../noema-style-guide.md`](../../noema-style-guide.md)で明示的に判断する。
