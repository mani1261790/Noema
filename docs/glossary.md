# 用語チップス辞書

Noema の教材本文では、`public/glossary.json` に登録した用語に自動でチップスを付けます。

教材ノートブック側に専用記法を埋め込む必要はありません。本文 HTML を読み込んだあと、ブラウザ側で通常テキストに含まれる用語を検出し、マウス hover、キーボード focus、クリックで説明チップスを表示します。

## ファイル

```text
public/glossary.json
```

このファイルは公開アセットとして配信され、学習アプリが `/glossary.json` から読み込みます。

## 形式

```json
[
  {
    "id": "td-error",
    "term": "TD誤差",
    "aliases": ["TD error", "temporal difference error"],
    "description": "現在の価値予測と、実際に得た報酬に次状態の価値を足した目標との差です。",
    "math": "\\delta_t = r_t + \\gamma V(s_{t+1}) - V(s_t)"
  }
]
```

## フィールド

- `id`
  - 任意の安定 ID。
  - 省略した場合は読み込み順の ID が使われますが、レビューしやすさのため明示してください。
- `term`
  - 表示名です。
  - 本文内で一致した場合、この用語にチップスが付きます。
- `aliases`
  - 別表記です。
  - 英語表記、略語、数式風の表記を入れられます。
- `description`
  - チップスに出す説明文です。
  - 改行は表示上も改行されます。
- `math`
  - 任意の TeX 数式です。
  - 文字列または文字列配列を指定できます。
  - 学習アプリ側で表示数式として描画します。

## 数式

`math` には TeX の中身だけを書きます。外側の `\\[ ... \\]` はアプリ側で付与します。

良い例:

```json
{
  "term": "価値関数",
  "math": "V^{\\pi}(s) = \\mathbb{E}_{\\pi}[G_t \\mid S_t = s]"
}
```

複数式を出したい場合:

```json
{
  "term": "ベルマン方程式",
  "math": [
    "V^{\\pi}(s) = \\mathbb{E}_{\\pi}[r + \\gamma V^{\\pi}(s')]",
    "Q^{\\pi}(s,a) = \\mathbb{E}_{\\pi}[r + \\gamma Q^{\\pi}(s',a')]"
  ]
}
```

## 自動注釈の対象

用語チップスは通常の本文テキストにだけ付きます。

対象外:

- `pre`
- `code`
- `a`
- `button`
- `input`
- `select`
- `math`
- `svg`
- KaTeX / MathJax の数式領域
- 確認問題パネル

コードや数式そのものを壊さないため、この対象外リストは広めにしています。

## 登録時の注意

- 長い用語を優先して一致させるため、`TD error` と `error` のような短すぎる alias は避けてください。
- 英数字だけの alias は単語境界を見ます。`V` や `a` のような一文字 alias は本文全体へ過剰に付くため避けてください。
- 日本語の短い一般語は避け、教材上の専門用語に限定してください。
- 用語の説明は教材本文の代替ではなく、読みながら迷ったときの短い補助説明にしてください。

## 確認方法

ローカルで学習アプリを起動します。

```bash
npm run dev -- --hostname 127.0.0.1 --port 3017
```

ブラウザで教材を開き、登録済み用語にチップスが付くことを確認します。

```text
http://127.0.0.1:3017/index.html?notebookId=rl-foundation
```

確認観点:

- 用語に下線付きのチップス UI が出る
- hover / focus / click で説明が出る
- `math` がある用語では数式が表示される
- コードブロックや既存の数式にはチップスが付かない
