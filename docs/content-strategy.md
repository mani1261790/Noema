# Noemaコンテンツ・掲載方針

ステータス: 決定済み・現行実装基準

決定日: 2026-07-11

## 1. 目的

Noemaは、AIでできることと、その仕組みを、直感と具体例からひもとく独立した技術メディアである。読者に順路を課さず、「なんとなく面白そう」という関心から記事へ入れることを優先する。

運営背景にはOIFがあるが、NoemaをOIFの勧誘サイトとして設計しない。Noema自身の内容と編集方針を前面に置き、OIFはAboutページの運営情報からのみ案内する。

## 2. 想定読者

- AIに関心はあるが、数式、コード、Terminalから始めると読みづらい人
- 技術が仕事や生活にどう関係するかを先に知りたい人
- 道具を使う話、何かをつくる話、仕組みの話を関心に応じて読みたい人
- 正確さを失わず、平易な説明を読みたい技術者

## 3. 公開画面の情報設計

- Level、段階、トラック、到達目標、前提知識を公開UIの分類ラベルとして表示しない。
- トップページでは注目記事を大きさの異なるカードで配置する。
- 入口になりやすい体験・活用の記事は大きく、対象が限られる開発・理論の記事は小さく掲載する。
- カードはテーマ、タイトル、要約、日付で内容を判断できるようにし、分類色だけに意味を依存させない。
- 記事一覧の検索条件はキーワードとテーマだけにする。
- 読者へ制作工程、公開予定、執筆体制を説明する文言を通常画面に置かない。
- 記事がない場合は「記事はまだありません」とだけ示す。

## 4. 編集用分類

記事の配置判断には次の内部メタデータを使う。これは編集用であり、公開画面へ名称を表示しない。

```yaml
stage: "experience" # experience | practice | advanced
track: "common" # common | development | theory
outcome: "編集時に確認する記事の狙い"
prerequisites: []
topics:
  - "ai-tools"
tags:
  - "NotebookLM"
```

| 内部値 | 編集上の扱い | トップページ |
| --- | --- | --- |
| `experience` | 初めて触れる人にも届く体験記事 | 大きいカード |
| `practice` | 日常や制作へ広げる記事 | 大きいカード |
| `advanced` + `development` | 開発環境や実装を扱う記事 | 小さいカード |
| `advanced` + `theory` | AIや数理の仕組みを扱う記事 | 小さいカード |

`experience`と`practice`は`track: common`、`advanced`は`development`または`theory`とする。Codexの入口記事は非開発者向け体験までとし、TerminalやGitを前提にしない。

## 5. カード表現

- DADSのカード仕様とデジタル庁ホームページの適用例に従い、白背景、1pxの四辺外周、24px角丸とする。
- カード全体を1つのリンクとし、カード内に別のリンクや操作を置かない。
- 左辺だけを太くする、片側だけに色線を置く、といった表現は禁止する。
- タイトルリンクは常時下線付きにし、リンクであることを色だけに依存させない。
- 四辺の枠とタイトル下線に、体験`#9A4B00`、活用`#00645F`、開発`#4355A5`、理論`#7A3E87`の内部分類色を使う。
- hover時は各記事の内部分類色による4pxの内側アウトライン、同色のタイトルと矢印を表示する。focus時は分類に依存せず、黒4pxと黄のフォーカスリングを表示する。
- カードの大小、テーマ名、要約を併用し、分類色だけで記事の位置付けを伝えない。

## 6. テーマとタグ

テーマは長期的に変わりにくい目的別分類とする。

1. AIを使う
2. AIとつくる
3. 知識と作業環境
4. 開発の基礎
5. AIの仕組み
6. 数理と理論

ChatGPT、NotebookLM、Codex、Obsidian、Python、Cloudflare等の製品名・技術名はタグとして管理する。

## 7. NoemaとOIFの関係

- Noemaの名称、編集方針、閲覧体験を最優先する。
- ヘッダー、記事カード、記事末尾にOIFの勧誘CTAを置かない。
- OIFへのリンクはAboutページ内の運営情報から`https://oif-ai.com`へ張る。
- 記事分類をOIFの組織構成として説明しない。

## 8. 受入条件

- 公開画面にLevel、学習段階、発展トラック、学習順序が表示されない。
- 入口向け記事は大きく、専門寄りの記事は小さく表示される。
- すべての記事カードが分類色1pxの四辺外周と24px角丸を持ち、左辺だけの線や分類色の面塗りを持たない。
- キーワードとテーマから記事を探せる。
- 制作工程や運営都合を説明するメタ的な文言が公開画面にない。
- OIFへの外部リンクはAboutページだけにある。
