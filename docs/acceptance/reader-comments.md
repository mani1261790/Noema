# 読者の質問・コメント

## 今回の範囲

一般公開の記事末尾にコメント欄を追加。読者アカウントは作らず、自己申告の表示名で投稿し、運営の承認後に公開する。返信は1段まで。Studio に承認・非表示・運営返信の管理画面を追加した。本文引用、AI返信案、返信通知は含まない。

- 表示は3スレッドずつ。長文と返信は折りたたみ、入力フォームも操作時だけ開く。
- 40文字の表示名、2,000文字の本文。プレーンテキストとして表示し、HTMLは実行しない。
- 読者と運営は別バッジ。運営の表示名は認証済みStudioのプロフィールから取得し、メールは公開しない。
- 公開操作・運営返信は `canEdit` 権限を必要とし、担当者を記録する。
- コメント公開は記事と返信先の公開状態を確認する。親が非表示・削除になると返信も公開一覧から見えなくなる。
- ブラウザ保存の256-bitランダムキーで自分の投稿を削除できる。DBにはSHA-256のみ保存。削除時は本文・名前・キーを消し、関係を保つID・日時を残す。ブラウザ保存を消した場合は削除キーを復元できない。
- 投稿IDで再送を重複排除する。失敗時は入力を維持し、削除キーは送信前に保存する。
- 同一Origin、12 KiBの本文上限、毎分5回/IP、全体500件/24時間、記事ごと承認待ち50件、スレッド返信20件、honeypot。コメントDBにIPは保存しない。
