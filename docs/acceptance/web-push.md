# 新着記事の Web Push

RSS の導線と配信を終了し、`/updates` から端末ごとに通知を登録・解除する。旧 `/rss.xml` は 410 を返す。

## 配信と運用

- Studio / MCP 共通の D1 公開トランザクションで、初回の一般公開を検出する。既存記事、修正、再公開、限定公開では通知しない。
- Studio の毎分 Cron が最大 30 件を処理する。送信は 5 並列、失敗は最大 5 回、24 時間まで再試行する。404 / 410 の購読は削除する。
- 購読は最大 10,000 件。登録 API は IP ごとに毎分 20 回、4 KiB まで。送信先はブラウザの既知の Push サービスに限定する。
- 登録は 180 日で失効し、通知設定ページで有効な登録を確認したときに延長する。送信記録は 7 日で削除、記事ごとの配信済み識別は再送防止のため保持する。
- 公開鍵は Wrangler vars、秘密鍵は GitHub の `PUSH_VAPID_PRIVATE_KEY`。Studio にのみ秘密鍵を渡す。鍵の変更は既存購読に影響するため、通常のデプロイで再生成しない。
- 権限ダイアログは登録ボタンを押したときだけ表示する。iPhone / iPad はホーム画面から開く手順を案内する。
- 配信にはブラウザ / OS の設定と通信状況が影響する。Worker が送信直後に停止した場合は再送されうるため、通知タグも記事単位にする。
